# ScheduleGo 📅

**ScheduleGo** adalah aplikasi web jadwal pelajaran sekolah interaktif yang siap di-deploy langsung ke **GitHub Pages**.

## 🌟 Fitur Utama
- 🗓️ **Jadwal Senin - Jumat**: Menampilkan seluruh mata pelajaran (Informatika, Coding, Matematika Lanjutan, Matematika Wajib, Fisika, Bahasa Inggris, Bahasa Inggris Lanjutan, PJOK, PKN, Sejarah) dan jam istirahat.
- 🕒 **Jam Digital & Status Real-time**: Indikator otomatis mata pelajaran yang sedang berlangsung.
- 📝 **Catatan & Tugas**: Fitur menyimpan catatan tugas/PR untuk setiap mapel (tersimpan di browser via `localStorage`).
- 🔍 **Pencarian Cepat**: Cari mata pelajaran secara instan.
- 🌙 **Dark Mode**: Dukungan mode gelap dan terang.
- 📱 **Responsive Display**: Tampilan nyaman di HP, Tablet, maupun Laptop.

## 🚀 Cara Upload ke GitHub Pages

1. Buat Repository Baru di GitHub (misal: `ScheduleGo`).
2. Extract file `ScheduleGo.zip` ini, lalu upload seluruh isinya (`index.html` dan `README.md`) ke repository kamu.
3. Buka **Settings** > **Pages** di repository GitHub tersebut.
4. Pada **Branch**, pilih `main` atau `master`, lalu klik **Save**.
5. Tunggu beberapa detik, website kamu siap diakses secara online!
